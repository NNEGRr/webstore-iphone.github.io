Чтобы превратить этот сайт в полноценное приложение на вашем iPhone, выполните следующие шаги:

  1. Обязательно откройте этот сайт через стандартный браузер Safari.
  2. В нижней панели браузера нажмите на кнопку «Поделиться» (квадрат со стрелкой вверх).
  3. Прокрутите появившееся меню немного вниз и выберите пункт «На экран "Домой"».
  4. При необходимости измените название приложения и нажмите кнопку «Добавить» в правом верхнем углу.

После этого на экране вашего iPhone появится иконка. Приложение будет открываться во весь экран, без адресной строки браузера.
